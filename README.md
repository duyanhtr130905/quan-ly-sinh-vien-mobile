# Quan Ly Sinh Vien Mobile

Android-first mobile shell for managing students and classes.

## Stack

- React Native
- Expo SDK 57
- TypeScript
- Expo Router

## Main modules

- **Sinh viên** — student management flows.
- **Lớp** — class management flows.

Hobby management belongs to future Student flows; it is not a top-level module.

## Run locally

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npm start
```

Launch on a running Android emulator:

```bash
npm run android
```

If the emulator is not already running, open it from Android Studio's Device Manager first, then run `npm run android`.
